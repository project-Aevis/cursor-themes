# Aevis Cursor Themes

Modern cursor themes designed for X11 and Wayland sessions in the Aevis Desktop Environment.

Part of the **[Project Aevis](https://github.com/project-Aevis)** suite.

## Installation

```shell
mkdir build
cd build
cmake -DCMAKE_INSTALL_PREFIX=/usr ..
make
sudo make install
```

Installed to `/usr/share/icons/` for system-wide availability.
